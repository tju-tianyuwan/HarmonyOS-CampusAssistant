# 学生端视觉调整

设计读取：保留现有学习流程与绿色识别的原生 ArkUI 视觉更新。设计变化 4/10、动效 2/10、密度 5/10。

审视：旧界面混用高饱和绿、蓝紫渐变和不同圆角；浅灰辅助文字对比不足；课程首页装饰占比高；小组创建表单缺少清晰分组。保留课程周历、四项主导航、课次资料、答题反馈、笔记编辑及常驻 AI 入口。

采用 Taste Skill 的审视优先、内容层级、颜色与形状一致性原则。该技能的网页营销素材、React/CSS、SEO、双主题与网页性能指标不适用于本次原生产品界面更新；沿用现有浅色模式、ArkUI 系统字体和系统图标，不安装网页依赖、不添加装饰图片。深色适配不在本次改动范围。

学生端主色 #176B55、正文 #20382F、次级文字 #52665D、辅助文字 #63746B、页面底色 #F4F7F5。卡片圆角 16，控件 12，标签 8。课表课程颜色与答题正误颜色保留语义区别。共享页面由 LearningTheme 根据角色选择颜色，教师端保留原主题。

布局覆盖：手机课表、平板课程列表、课程首页（手机/平板）、课程与笔记入口、AI学习小组、刷题、常驻导航及 AI 入口；已有笔记编辑页复用学生主题。课程 AI 页面减少装饰、修复提示框超出消息气泡、移除学生单助手界面的旧多角色装饰。页面数据来自现有接口，不修改课程、排课或笔记数据。

验收（2026-09-19）：ArkTS 编译及 assembleHap 打包成功，保留 SDK 弃用 API 提示及开发包未签名提示。已在用户启动的手机（1320×2856）和平板（2880×1920）模拟器安装，并以已有学生账号检查课程首页、课表/课程列表、学习小组、课程、刷题、笔记入口及 AI 对话显示。手机刷题为可滚动内容；选项随文本增高。未提交答案、发送消息或创建课程/小组/笔记。验证截图位于项目 .codex-run/student-*.jpeg。

主色、正文、次级文字和辅助文字在白底上的对比度分别约 6.42、12.59、6.15、4.95；在页面底色上最低 4.59。检查针对本轮主题文字，不代表全应用完整无障碍认证。深色模式、超大系统字体及实体设备未覆盖。
