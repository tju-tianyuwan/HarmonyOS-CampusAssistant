# 智慧伴学 HarmonyOS 客户端

`client/` 是连接 FastAPI 服务端的网络版 HarmonyOS 客户端，使用 ArkTS/ArkUI Stage 模型，支持 API 12+ 的 Tablet、2in1 和 Phone。平板保持横屏，手机启用自动旋转并提供竖屏紧凑布局。

## 页面

- 登录与课程库：邮箱/学校账号注册登录，个人知识空间，创建或通过邀请码加入课程。
- 账号安全：邮箱验证码找回密码、验证当前密码后修改密码、学校账号绑定找回邮箱；改密后所有设备需重新登录。
- 概览：课程信息、官方课时、个人笔记、班级笔记和快捷入口。
- 课程：学生按横向时间线查看课次，进入后可看转写、教师发布提纲、课程资料和关联个人笔记；录音、分片上传、提纲生成与发布仅教师可用。
- AI 聊天：学生通过右下角常驻 AI 入口进入，使用单一 RAG 助手依据课程知识回答问题。
- AI学习小组：真人成员与组员 A-D 四个 Agent 讨论，支持缓冲调度、@指定 Agent、冷场引导和学习总结。
- 刷题：根据课程知识库与用户要求生成选择题。
- 笔记：班级笔记、Markdown/AI 笔记和矢量手写笔记；手写本机草稿、离开提示、恢复与跨屏缩放。触控笔压力映射线宽并随笔迹保存，M-Pencil 效果待真机验证。
- 教师资料：汇总官方课堂提纲和教师上传文件，点击进入对应课次编辑、审核提纲；不展示归档笔记。
- AI学习小组：新建时选择单 Agent 或多 Agent；单 Agent 由 `@AI` 触发，多 Agent 沿用角色讨论和学习总结，成员与结束操作收进设置。
- 设置：服务器地址、NFC、系统隔空传送和跨端接续。握拳抓取/张手释放需要支持该功能的 API 20+ 华为真机。

## 教师界面 1.0

教师进入课程后先显示课程首页；四项导航为课堂、AI数据、AI学习小组、资料。资料汇总官方课堂提纲与课次上传文件，点击后进入对应课次查看、编辑与审核。
教师端移除笔记、聊天群和独立提纲/审核入口，学生笔记功能及既有数据保留。竖屏使用等宽导航和课次分段切换。
具体变更与部署状态见 `TEACHER_UI_V1.md`。

## 学生手机界面 2.0

手机设备 (`deviceType === 'phone'`) 的学生首页显示个人周课表；平板、电脑和教师首页仍使用原课程库。
课表从登录用户的 `/timetable` 接口加载，按已加入课程自动汇总教师设置的上课时间，支持上一周、下一周、本周、1–12 节、1–30 周、单双周和教室。
教师新建课程时必须填写上课时间；已有课程通过课程卡片右上角的日历按钮设置或修改，可添加多个时段。
学生加入课程后自动刷新课表，只有查看与进入课程入口，没有排课或修改学期日期的权限。教师改课后，学生刷新课表即可获取最新安排。
“全部课程”保留所有课程入口；教师未安排时间的课程单独列出，不自动编造时间。重叠课程合并为可展开的冲突条目。

后端 `CourseSchedule` 表按课程保存安排，读取通过登录用户的课程成员关系隔离，写入仅允许该课程教师。
旧 `TimetableSettings` 和 `TimetableEntry` 保留但不再参与正式课表，不把学生旧排课转换成教师安排。
上线前先在 `server` 目录运行 `.venv\Scripts\python.exe migrate_timetable.py` 备份并创建表，再重启后端并安装新客户端。部署现状见 `STUDENT_MOBILE_V2.md`。

手机课程内导航、刷题、学习小组、AI、笔记界面提供紧凑布局。AI 入口固定在右下方独立底栏，避免覆盖页面内的提交、保存和发送操作。

## 打开与运行

1. 安装 DevEco Studio 6.0+ 和 HarmonyOS SDK API 12+。
2. 打开本 `client/` 目录并等待 Hvigor Sync。
3. 在 `Project Structure > Signing Configs` 中为本机生成签名。
4. 启动后端，再运行 `entry` 模块。

模拟器访问宿主机使用：

```text
http://10.0.2.2:8000/api/v1
```

真机联调时，在应用设置页改为电脑局域网地址，并确保后端通过 `--host 0.0.0.0` 启动。

## 源码结构

```text
client/
├─ AppScope/                       应用配置与图标
├─ build-profile.json5             SDK、产品和模块配置
├─ hvigor/                         Hvigor 配置
└─ entry/src/main/
   ├─ module.json5                 Ability、权限和横屏配置
   ├─ ets/
   │  ├─ entryability/             应用入口与跨端恢复
   │  ├─ common/                   主题与通用组件
   │  ├─ model/                    前后端数据模型
   │  ├─ pages/                    课程、AI、刷题、笔记等页面
   │  └─ service/
   │     ├─ Api.ets                HTTP、上传和 SSE 封装
   │     ├─ GlobalState.ets        用户、课程与接续状态
   │     └─ collab/                NFC 与局域网协同
   └─ resources/                   字符串、颜色、图标和页面清单
```

## 构建

DevEco Studio 中选择 `entry` 模块后执行 `Build Hap(s)`。签名材料是开发机私有配置，不保存在仓库中；首次构建必须在 IDE 中重新配置签名。

生成的 `.hvigor/`、`oh_modules/`、`entry/build/` 和 HAP 文件均已加入 `.gitignore`。
